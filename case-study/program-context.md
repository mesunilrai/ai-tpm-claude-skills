# Enterprise Identity Modernization — Case Study

## Purpose

Provide a shared synthetic enterprise program for evaluating the AI TPM Skills consistently.

This scenario is fictional and contains no proprietary company information.

## Program Overview

A large enterprise is modernizing its employee identity platform across multiple applications and business units.

The program will replace the current authentication approach with a modern identity architecture while minimizing disruption to existing users and downstream applications.

## Program Objectives

- Modernize enterprise authentication.
- Improve security and maintainability.
- Reduce dependency on legacy identity components.
- Migrate participating applications in controlled phases.
- Maintain business continuity during migration.

## Program Scope

The program includes:

- Identity platform changes
- Application authentication integrations
- API and interface changes
- Security validation
- Application testing
- Data and configuration migration where required
- Production rollout
- Post-release validation

## Program Participants

The synthetic program includes:

- Identity Engineering
- Application Engineering
- Security
- Data / Integration Engineering
- QA / Testing
- Infrastructure / Platform Engineering
- Program Management
- External identity vendor

These are scenario participants only. Specific ownership must be established from the input provided to each Skill.

## Initial Program Constraints

- Target production launch: 8 weeks
- Multiple applications must be migrated.
- Some applications have limited maintenance windows.
- The identity vendor has an external delivery dependency.
- Security validation is required before production rollout.
- Application teams have competing priorities.

## Known Program Characteristics

The program intentionally contains:

- Cross-team dependencies
- Vendor dependencies
- Security considerations
- Integration dependencies
- Schedule constraints
- Potential technical change impacts
- Decisions requiring trade-offs
- Incomplete information in some scenarios

## Evaluation Principle

The Skills must not assume that every characteristic listed above applies to every scenario.

A test input should establish which facts are relevant.

The purpose of this case study is to evaluate whether the Skills can reason across a realistic technical program while maintaining evidence discipline.
